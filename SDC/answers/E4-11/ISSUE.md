## 检查内容

- `@Param("id")` 与 SQL `#{id}` 一致，且申请 ID 与地址 ID 分别断言。
- 正常关联下，`ca_` 前缀把地址列映射到 `companyAddress`，验证地址名、联系人和城市。
- 第二个申请映射至另一地址，作为独立额外输入核验关联行与字段映射。
- 左连接无地址时关联属性为 null，查询 ID 不存在时结果为 null。
