## 靶点

portal 搜索、品牌商品列表、首页推荐商品各自写“已上架且未删除”；首页新品和人气推荐 SQL 只过滤上架；search 导入也写了一份，商品详情按主键读取。分析 DRY 和逻辑归属，用开发视图说明各模块依赖。

## 验收准则

- portal 三个 Java 入口共用一处可见条件；以特征测试记录改前改后的查询条件。
- 首页 SQL 是否补删除条件属于行为修正；先记录旧行为并说明理由，用实际 SQL 验证改前和改后。
- 说明新增一种不可见情形时改前、改后修改位置数，并区分 SQL 与跨模块边界。
- 不改表结构、生成代码和公开接口；search 只讨论，不要求改实现；不新增审核规则。
