# 改后

`updatePublishStatus` 在 mapper 返回正行数且 `publishStatus == 0` 时调用 `PmsProductUnlistingPort.notifyUnlisted` 一次；通知异常记告警并维持原返回行数。新增测试也验证内存适配器保存快照。

使用 JDK 17 fresh 执行：

```text
rtk env JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home mvn -pl SDC/E2 -am -DskipTests=false -Dtest=ProductUnlistingNotificationTest -Dsurefire.failIfNoSpecifiedTests=false test
```

结果：BUILD SUCCESS；`ProductUnlistingNotificationTest` 5 项通过，0 失败。人为抛出的通知异常产生一条 WARN，但测试确认服务仍返回 mapper 的 `1`。

随后运行 E2 全模块 fresh 验证：

```text
rtk env JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home mvn -pl SDC/E2 -am -DskipTests=false test
```

结果：BUILD SUCCESS；E1 3 项、E2 8 项通过，0 失败。
